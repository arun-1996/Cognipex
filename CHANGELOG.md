# Changelog

## Unreleased

### Added

- Added original featured illustrations to the published CVI and reticular activating system articles, including accessible alternative text and responsive WordPress image sizes.
- Added versioned WordPress pages for About, content standards, accessibility, privacy, terms, and cookie information, together with a structured responsive footer and published-route navigation.
- Added accessible visual-pathway and visual-crowding illustrations to the published CVI article, with explanatory captions that avoid presenting one universal CVI experience.
- Added the session-only Focus Grid game with three progressive visual-search boards, accessible number controls, mistake feedback, and no timer.
- Added the `cogpace/focus-grid` dynamic block for cognitive-game records using the `focus-grid` game key.
- Added immediate minus-one-point penalties for wall and boundary hits in Maze Navigator, including live and final score reporting.
- Added the session-only Maze Navigator game with five interactive grids, arrow-key and touch controls, accessible position feedback, and final move-count reporting.
- Added the `cogpace/maze-navigator` dynamic block for cognitive-game records using the `maze-navigator` game key.
- Added the session-only Rule Switch game with twelve alternating classification rounds, accessible text controls, explanatory feedback, and final scoring.
- Added the `cogpace/rule-switch` dynamic block for cognitive-game records using the `rule-switch` game key.
- Added the session-only Sequence Recall game with five progressive rounds, replayable numbered-shape sequences, accessible input controls, and final scoring.
- Added the `cogpace/sequence-recall` dynamic block for cognitive-game records using the `sequence-recall` game key.
- Added the session-only True or False game with ten shuffled questions, answer explanations, accessible controls, and final scoring.
- Added the `cogpace/true-or-false` dynamic block for cognitive-game records using the `true-or-false` game key.
- Redesigned query-loop article cards with an editorial content hierarchy and accessible interaction states.
- Redesigned the homepage around a local, decorative video hero with reduced-motion support.

### Changed

- Renamed the product, theme, core plugin, PHP namespace, blocks, content type, assets, and front-end identifiers to Cogpace.
- Replaced the public Editorial Policy with solo-publisher Content Standards, moved the canonical route to `/content-standards/`, and removed references to writers, reviewers, and named approvers.
- Removed the internal WordPress administration section from the public Cookie Information page through a targeted managed-content migration.
- Improved the homepage practice-card layout with a full-width three-column desktop grid, more balanced internal spacing, and compact “Start” actions while preserving 16:9 cards.
- Simplified the homepage hero headline to the concise statement “Elevate your mind.”
